title: "Interactive Tasking"
---

For terminal-style follow-on input, see [Interactive Tasking](/version-4.0/customizing/payload-type-development/15.-interactive-tasking) and the [agent message format](/version-4.0/customizing/payload-type-development/create_tasking/agent-side-coding/8.-interactive-tasking).

For versioned UTF-8 document editing, use the v4 [File Editor Protocol](/version-4.0/customizing/payload-type-development/create_tasking/agent-side-coding/file-editor-protocol), which reserves interactive message types `100`–`102` and adds refresh/save/close semantics with conflict detection.
